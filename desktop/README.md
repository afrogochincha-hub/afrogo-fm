# Afrogo FM para PC

Aquí se importará el código fuente completo y verificable de la última versión de escritorio conocida (v3.16.0). No se ha copiado aún el contenido de esa distribución ZIP, por lo que este directorio no es por ahora una app compilable.

## Para completar este módulo
- Importar fuentes Electron, preload, interfaz, assets, package.json y archivos de bloqueo.
- No añadir node_modules, música, datos de usuario, claves ni tokens.
- Confirmar las funciones existentes en pruebas reales antes de declararlas validadas.
