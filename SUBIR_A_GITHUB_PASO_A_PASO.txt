AFROGO FM — SUBIR A GITHUB SIN CONFLICTOS

ESTE ZIP YA TIENE LAS CARPETAS EN LA RAÍZ. No busques una carpeta interior llamada afrogo_fm_suite.

1. Cierra cualquier cuadro que diga “Resolve conflicts before Merge”. No uses Continue merge.
2. En GitHub Desktop, selecciona la copia limpia del repositorio afrogo-fm que clonaste en una carpeta nueva (por ejemplo afrogo-fm-limpio-2).
3. Usa Repository > Show in Explorer para confirmar que se abrió ESA carpeta nueva.
4. Extrae el ZIP en Descargas. Dentro deben verse directamente .github, android, backend, desktop, docs, README.md y este archivo.
5. Copia TODO el contenido extraído (incluyendo la carpeta oculta .github si Windows la muestra) y pégalo en la raíz de la carpeta afrogo-fm-limpio-2. Acepta combinar carpetas y reemplazar archivos cuando Windows lo pregunte.
6. MUY IMPORTANTE: el ZIP no incluye .git. No borres ni reemplaces la carpeta oculta .git que pertenece a la copia clonada. Tampoco copies ningún .env real, node_modules, música ni datos de usuarios.
7. Abre GitHub Desktop y revisa Changes. Deben aparecer los archivos nuevos/modificados, sin un cuadro de merge. Si vuelve a aparecer “Resolve conflicts before Merge” o un aviso de merge, detente y no pulses Continue merge; envía una captura.
8. En Summary escribe: AfroGo FM 3.31.0 / Android 1.9.0 - rediseño móvil y sesión persistente
9. Pulsa Commit to main.
10. Cuando aparezca Push origin, púlsalo y espera a que termine.
11. En GitHub, abre el repositorio y ve a Actions. Abre la ejecución más reciente. Comprueba que backend-check, windows-desktop y android-debug terminen en verde.
12. Descarga los artifacts de Windows y Android solo cuando el flujo finalice correctamente.

SI PUSH ORIGIN ES RECHAZADO:
No pulses Pull origin de inmediato. Toma una captura del mensaje para revisar primero cómo sincronizar sin descartar cambios.
